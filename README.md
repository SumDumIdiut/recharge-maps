# recharge-maps (Navigator)

Core infrastructure for loading and playing real-asset custom maps and switching between Base Game and B-Side. Required by the Navigator tab and by DOTnet's map hosting.

Part of [Recharge](https://github.com/SumDumIdiut/recharge): the app pulls this repo into its mods folder and `build-loader.ps1 -ModsDir` compiles it against the game's `Managed` folder.
